Run the full skill on any link

The full skill downloads the video, transcribes it with word timings and measures the voice, music and platform stats. It needs a machine that can reach the video site and Hugging Face (for the speech model).

1. In Claude Code, inside the repository

/dissect https://www.youtube.com/watch?v=VIDEO_ID

2. Or run the measuring script yourself

uv run .claude/skills/dissect/scripts/dissect.py "https://www.youtube.com/watch?v=VIDEO_ID" --depth standard

Missing something? python3 .claude/skills/dissect/scripts/doctor.py checks ffmpeg, uv, packages and network access and prints install commands.

3. Run this lab on your machine

python3 dissect-lab/server.py   # then open http://localhost:8765

Served locally, this page gets a form that sends a link straight to the skill and adds the result here.
